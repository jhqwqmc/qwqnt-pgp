# qwqnt-pgp

QwQNT 的 PGP 加密插件，使用本机 GnuPG 对 QQ 文本消息加密、签名和解密。加密消息以合并转发卡片发送。

## 安装

1. 安装 QwQNT 和 GnuPG。Windows 上可以使用 Gpg4win。
2. 将 `qwqnt-pgp.zip` 解压到 QwQNT 插件目录下的 `qwqnt-pgp` 文件夹。
3. 重启 QQ，在设置中打开「PGP 加密」。

## 使用

先在 GnuPG 钥匙串中准备自己的密钥和联系人的公钥，再在插件基本设置中选择「我的公钥」。

- **绑定公钥**：在设置页选择未绑定的好友，或输入数字 QQ 号，可给多个联系人绑定同一把公钥。每个 QQ 号只有一个绑定。
- **私聊与临时聊天**：在聊天详情的「加密」里选择一把联系人公钥，再点一次可解除绑定。
- **群聊**：在群详情的「PGP 加密成员」中，开启至少一位已绑定公钥的其他成员。
- **发送**：默认按 `Ctrl+/` 加密发送。启用自动加密发送后，使用 QQ 原有的发送按钮或快捷键即可。加密消息会用自己的私钥签名，自己也会被加入收件人。
- **解密**：默认可右键消息选择「解密」，也可以在基本设置开启自动解密。绿色表示签名有效且身份受本机信任，黄色表示身份未验证或无签名，红色表示缺少签名公钥或验签失败。

插件配置按登录的 QQ 账号保存。目前支持纯文本消息。构建包提供 Windows x64 合并转发模块，偏移由插件从本机 QQ 内核解析并缓存。

## 从源码构建

在 Windows x64 上构建。首次构建会下载 Zig 0.15.2 到项目的 `tools/`，后续构建复用同一版本。

```sh
pnpm install
pnpm build
```

## 发布

提升 `package.json` 版本号，将以 `[ci build]` 开头的提交推送到 `main`。GitHub Actions 会构建并发布 ZIP，已有同名标签或 Release 时跳过。

首次使用需在仓库设置启用 **Release immutability**，并添加 Actions Secret `RELEASE_SETTINGS_TOKEN`。此令牌只需该仓库的 **Administration: Read-only** 权限，用于在发布前确认不可变设置已启用。
